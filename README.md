## 📖 Описание проекта

**Beauty Salon** — это полноценная CRM-система, автоматизирующая работу салона красоты. Проект решает три ключевые задачи:

1. **Для клиентов** — удобная онлайн-запись на услуги с автоматической проверкой доступности мастеров.
2. **Для мастеров** — личный кабинет с расписанием, статистикой и управлением статусами записей.
3. **Для администраторов** — панель управления с общей аналитикой, KPI и загрузкой всех мастеров.

Система предотвращает двойное бронирование, проверяет график работы мастеров, учитывает обеденные перерывы и предоставляет детальную статистику по выручке и популярности услуг.

## 💡 Особенности реализации

### 1. Многоуровневая валидация записей
В форме `AppointmentForm` реализована комплексная проверка данных:
- **Валидация на уровне формы** — для мгновенной обратной связи и улучшения UX.
- **Валидация на уровне модели** — для гарантированной целостности данных в базе.
- **Проверка графика мастера** — учет рабочих дней, часов и обеденного перерыва.
- **Математика пересечения интервалов** — строгая проверка на двойное бронирование по формуле: `(A.start < B.end) AND (A.end > B.start)`.

### 2. AJAX-фильтрация без перезагрузки
При выборе услуги в форме записи список доступных мастеров обновляется асинхронно через JavaScript `fetch()` без перезагрузки страницы. При этом реализован принцип *graceful degradation*: если у пользователя отключен JavaScript, серверная фильтрация в `forms.py` продолжит корректно работать.

### 3. Разграничение прав доступа
- Использование декораторов `@login_required` и `@staff_member_required` для защиты маршрутов.
- Проверка поля `user.role` в шаблонах и представлениях для разделения функционала интерфейса.
- Связь `OneToOneField` между моделями `CustomUser` и `Master` для безопасной и удобной привязки учетной записи к профилю сотрудника.
